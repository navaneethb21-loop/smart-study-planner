# Smart Study Planner 📚

A beginner-friendly Python program that creates a personalized study plan based on the user's available time, mood, subjects, and difficulty levels.

## Features

- Takes the user's name and available study time
- Creates a short or detailed study plan
- Considers the user's mood
- Takes three subjects as input
- Assigns difficulty levels to subjects
- Allocates study time based on difficulty
- Creates a study order
- Generates a timetable
- Adds a 10-minute break for longer study sessions
- Handles invalid study-time input

## How to Run
